## 独立判据

review_adc_bins.py 使用 Fraction 精确表示理想 ADC 标度 3.3/4096、Vout 增益 2、电流零点 1.65 V 和增益 0.1 V/A。分别计算码箱两端，再要求整个区间的绝对值上界不超过原 0.1 V / 0.1 A，且两个码都不是 0 或 4095。

执行两个一维全码扫描，共 8192 点，并非扫描所有 4096×4096 组合：

- 扫描全部 4096 电压码，电流码固定为有效内码 2048。
- 扫描全部 4096 电流码，电压码固定为有效内码 1。

每一点先将独立 C 和 Python 控制器置为故障锁存，再提交明确 clear 请求及实际测量接口的证据，要求两实现结果逐字段一致，并与独立有理数判据一致。另检查原生 C adapter 对缺失、不可观测、NaN、Infinity、负界限和低于测量值的证据均拒绝解除。
