# 理想同步 Buck 的 PWM 开关证据

本步新增实际时域电压切换的 Python 开关模型，与此前平均模型并存。`switching_buck.py` 在每个 PWM 周期内令开关节点电压为 **9 V 或 0 V**；不以 `duty×9 V` 代替开关波形。高侧段和低侧段分别积分，电感电流和电容电压跨边沿连续。只使用 Python 标准库，无器件损耗、效率或硬件测量结论。

## 时序和模型

参数仍是教学假设：输入 9 V、L=220 µH、C=470 µF；固定占空比工况负载 4 Ω。控制扰动工况沿用默认 Kp=0.03、Ki=30、20 ms 软启动，在 50 ms 将负载从 4 Ω 改为 2 Ω。

- PWM 频率 **50 kHz**，周期 **20 µs**；控制器每个 PWM 周期更新一次，与原控制采样周期一致。
- 周期起点读取当前输出电压，立即计算 PI 并更新该周期占空比。高侧从周期起点导通至 `duty×20 µs`，之后低侧导通至周期结束。
- 本模型计算延时为零，没有下一周期影子寄存器加载、死区或 ADC 量化。此时序是教学定义，不代表 C2000 固件的实际时序配置。
- 两个开关拓扑复用原功率级方程，向 `plant_step()` 传入的开关状态严格为 0 或 1。每个边沿都作为积分分段边界，段内用 RK4。
- 最大积分子步分别为 **0.5 µs / 0.25 µs**；各段用 `ceil(段长/最大子步)` 等分，因此实际子步可能更短。改变积分精度不改变 PWM 周期或控制采样周期。
- 初始电感电流和输出电压均为零，不在开关边沿重置状态。同步模型允许电感反向电流，也没有对电容电压做非负裁剪；不包含二极管续流/DCM 状态切换或真实钳位。

本步没有把现有采样保护接入开关模型，也没有改变已验证的保护实现或阈值。保护与实际开关器件的联动属于尚未完成的范围。

## 固定占空比稳态

固定 `D=2/9`，高侧导通时间约 4.444444 µs、低侧约 15.555556 µs。运行 60 ms，使用最后 20 个完整周期（59.6–60.0 ms）统计。

周期均值使用每个积分子步的梯形积分；峰峰值是该周期所有积分节点（含开关边沿）的最大值减最小值。报告的是 20 个周期峰峰值的平均，原始数据也包含各周期最大值。

| 指标 | Python，最大子步 0.25 µs | 基本解析值 |
|---|---:|---:|
| 输出周期均值 | 2.0000002304 V | `D×Vin = 2 V` |
| 电感电流周期均值 | 0.5000000757 A | `Vout/R = 0.5 A` |
| 电感峰峰纹波 | 0.1414220378 A | 0.1414141414 A |
| 输出峰峰纹波 | 0.7521450496 mV | 0.7522028799 mV |

对同参数的原平均功率级另行从零运行 60 ms，末态输出为 **2.0000002104 V**、电感电流 **0.4999998715 A**，与开关模型周期均值及直流关系一致。平均模型本身没有 PWM 纹波，不能用其平滑曲线验证纹波。

小纹波近似关系为：

```text
ΔiL ≈ (Vin - Vout) * D / (L * fs)
ΔvO ≈ ΔiL / (8 * fs * C)
```

第一式来自高侧导通段的电感电压积分；第二式将电容电流近似为零均值三角波积分。只用于当前理想、无 ESR、稳态小纹波条件。电感纹波相对解析式偏差约 **+0.005584%**，输出纹波约 **-0.007688%**。固定占空比最后 20 个周期的输出均值跨度约 4.95e-8 V，表明该统计窗口内残余启动变化很小；这些数值精度不是硬件测量精度。

## 默认 PI 的负载阶跃

运行 100 ms，保留完整控制采样点和周期统计。为了与原平均模型公平比较，下面的响应指标均在同样的 **20 µs 周期起点采样网格**计算，不声称等于连续时间峰值。

| 指标 | 原平均模型 | PWM 开关模型，0.25 µs 最大子步 |
|---|---:|---:|
| 事件后最大绝对偏差 | 0.243512 V | 0.242804 V |
| 采样点最大超调 | 9.659106% | 9.574292% |
| 恢复至 2 V±2% | 5.12 ms | 5.10 ms |
| 最后 10 ms 采样点平均误差 | +0.001361 mV | +0.001371 mV |

整个 100 ms 内，两种模型的同期输出采样最大差约 **2.01615 mV**。这里两套 PI 分别使用各自模型的采样反馈，不能将全部差异解释为单独的功率级误差。

在开关模型最后 20 个周期（99.6–100 ms），输出周期均值为 **2.0002799409 V**、电感电流均值为 **1.0001399299 A**，输出纹波 **0.7522328376 mV**，电感纹波 **0.1414361608 A**。周期均值与固定 PWM 相位的采样值不同：PI 调节的是周期起点采样值，不能用采样点误差代替整个周期的直流均值误差。这个约 0.280 mV 的周期均值偏置保留在数据中。

## 定向积分精度检查

保持 PWM、采样、PI 和事件时序不变，只将最大子步从 0.5 µs 减到 0.25 µs，两种工况均重跑。

| 指标 | 固定占空比 | PI 负载阶跃 |
|---|---:|---:|
| 周期起点输出轨迹最大绝对差 | 3.4461e-13 V | 3.9968e-14 V |
| 稳态周期输出均值变化 | -9.4798e-9 V | -9.5625e-9 V |
| 输出峰峰纹波变化 | +1.87800 µV | +1.84017 µV |
| 输出纹波变化占细步长结果 | 0.249686% | 0.244628% |
| 恢复时间变化 | 不适用 | 0 |

电感纹波变化小于 7e-15 A。输出纹波仍有约 0.25% 的网格变化，而周期起点状态几乎不变：前者主要反映段内电压极值取样分辨率，周期均值的微小变化还包含梯形积分分辨率。不能仅凭周期起点轨迹接近就宣称峰峰纹波已经精确收敛。这里报告一次细化结果，没有估计完整收敛阶或连续时间极值的严格误差界。

## 原始数据的保存范围

全部新结果位于 `switching_results/`，没有覆盖 `results/` 中的平均模型 CSV。

| 文件后缀 | 保存范围 |
|---|---|
| `fixed_duty_*_control_samples.csv` | 0–60 ms，每 20 µs 一点，共 3,001 行 |
| `fixed_duty_*_cycles.csv` | 0–60 ms，全部 3,000 个 PWM 周期的均值和峰峰值 |
| `fixed_duty_*_waveform.csv` | 59.6–60.0 ms，最后 20 周期的全部积分节点与边沿 |
| `controlled_load_step_*_control_samples.csv` | 0–100 ms，每 20 µs 一点，共 5,001 行 |
| `controlled_load_step_*_cycles.csv` | 0–100 ms，全部 5,000 个 PWM 周期 |
| `controlled_load_step_*_waveform.csv` | 49.8–50.6 ms（40 周期）及 99.6–100 ms（20 周期） |

`*` 分别为 `0p5us` 或 `0p25us`。高分辨率波形有选择地保存事件附近和稳态窗口，其余长时响应仍可由完整控制采样与周期统计复查。

波形在开关边沿左右保存重复时刻：`switch_voltage_v` 跳变，而 `output_v`、`inductor_current_a` 相同。`point`、`high_side_on` 和 `cycle` 列区分段起点、段内点及段终点。画阶跃波形时应保留这些成对的边沿记录。不同窗口之间有时间间隔，不能跨窗口直接积分或连成一条连续的开关脉冲。

其他结果：

- `metrics.json`：两个积分精度的稳态/控制响应、解析式和平均模型对照。
- `parameters.json`：实际参数、PWM/控制时序、保存窗口和解释器版本。
- `*_step_comparison.csv`：两个精度下同期控制采样输出和电流差。
- `step_comparison_metrics.csv`：积分细化造成的均值、纹波、轨迹和恢复指标变化。
- `controlled_load_step_averaged_comparison.csv`：开关模型与平均模型的同期输出及占空比。
