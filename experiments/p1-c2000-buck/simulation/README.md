# 独立教学 Buck 平均模型

这是使用 Python 标准库独立编写的理想同步 Buck 平均模型，用于理解电压 PI、软启动以及输入/负载扰动。没有复制 TI 源码，不是 TI 原厂复现，也不是 MCU 固件或硬件测量。

本页保留第一小步的模型与结果。后续增加的采样保护、故障锁存与显式清除见 [第二步说明](PROTECTION.md)；其正常工况已经验证与本页模型逐样本一致。

第三步 [有限 PI 比较与积分步长检查](PI_COMPARISON.md) 已完成，保留全部九组候选结果；本文默认模型参数保持不变。

## 模型、参数和时序

状态变量为电感电流 `iL` 与输出电压 `vO`，电阻负载为 `R`：

```text
L * diL/dt = duty * vin - vO
C * dvO/dt = iL - vO/R
error[k] = reference[k] - vO[k]
integral_candidate = integral[k-1] + Ki * Ts * error[k]
duty[k] = clip(Kp * error[k] + integral[k], 0, 0.95)
reference[k] = 2 * min(t[k]/0.020, 1) V
```

当积分候选值会让输出进一步进入占空比饱和时，保持积分器；误差方向有助于退出饱和时继续积分。占空比限幅是数学控制器的输出限制，**不是过流或过压保护**。

全部数值为本教学模型的假设与整定选择，未从 TI 电路或固件提取：

| 参数 | 数值 |
|---|---:|
| 输入电压 / 目标输出 | 9 V / 2 V |
| 电感 L / 电容 C | 220 µH / 470 µF |
| 标称电阻负载 | 4 Ω，即目标电压下 0.5 A |
| PI 比例系数 Kp | 0.03 duty/V |
| PI 积分系数 Ki | 30 duty/(V·s) |
| 控制周期 Ts | 20 µs（50 kHz 采样） |
| 数值积分 | RK4，每个控制周期 4 个子步，即 5 µs |
| 软启动参考斜坡 | 0→2 V，20 ms |
| 每个工况时长 | 100 ms，初始电压、电感电流、积分器均为零 |

每个采样点先施加该时刻的输入/负载，再读取当前状态、更新 PI，然后将占空比保持到下一采样点。模型没有计算延时。CSV 记录更新控制器时的状态、输入/负载和随后一周期的占空比命令，含 t=0 与最终端点，共 5,001 行；最终端点命令不再积分。

50 kHz 是控制采样频率，**没有在此建模 PWM 开关频率或开关纹波**。本模型允许有符号电感电流，适用于理想同步功率级的平均描述；未实现二极管非负电流约束或 DCM 模式切换。电感/电容理想，无 ESR、导通损耗、死区、ADC 量化或硬件延迟，不估算效率。普通电压 PI 的动态性能不代表商业数字电源设计。

## 工况与指标定义

| 工况 | 条件 |
|---|---|
| `startup` | 9 V、4 Ω，观察软启动 |
| `load_step` | 软启动后，在 50 ms 将负载 4 Ω→2 Ω，输入保持 9 V |
| `input_step` | 软启动后，在 50 ms 将输入 9 V→7.5 V，负载保持 4 Ω |

稳态误差取最后 10 ms 输出采样的算术平均减去 2 V。超调是整个 100 ms 记录中输出高于 2 V 的最大值，除以 2 V。最大绝对偏差从事件时刻开始计算；启动工况的事件时刻为 **20 ms 参考斜坡结束**，另外两个工况为 50 ms 扰动时刻。

恢复时间为事件后首次进入并一直保持在 2 V ±2%（±40 mV）范围内至记录结束的时间，且进入后至少剩余 2 ms 观察记录。若未满足，JSON 为 `null`，CSV 为空；这是有限记录内的恢复指标，不是对后续无限时间的稳定性证明。时间分辨率为 20 µs。

## 本轮仿真结果

| 工况 | 稳态误差 (mV) | 全程超调 (%) | 事件后最大绝对偏差 (V) | 恢复至 ±2% (ms) |
|---|---:|---:|---:|---:|
| 启动 | -0.0000434 | 0.00000628 | 0.365373 | 10.48 |
| 负载阶跃 | +0.001361 | 9.659106 | 0.243512 | 5.12 |
| 输入阶跃 | -0.064759 | 0.621875 | 0.469224 | 13.98 |

启动的 10.48 ms 是斜坡结束后的恢复时间，从 t=0 算为 30.48 ms。非常小的最终误差来自理想模型与有限数值精度，不代表硬件的可测精度。输入阶跃的最大偏差仍约为目标电压的 23.46%，表明这个最小 PI 的扰动响应有明显改善空间；本步没有进行大范围参数优化。

独立正确性检验绕过 PI 和软启动，以固定占空比 0.25、输入 9 V、负载 4 Ω 从零积分 60 ms，解析稳态为 `vO = duty*vin = 2.25 V`、`iL = vO/R = 0.5625 A`。实际得到 **2.250000236677 V、0.562499855402 A**，均在 1e-5 的绝对容差内。

`test_buck.py` 另对三个闭环工况检查有限数值、占空比范围、软启动端点，以及预先设置的教学检查条件：最终误差小于 20 mV、超调小于 10%、事件后偏差小于 0.5 V、恢复时间小于 30 ms。两项测试（其中一项含三个闭环子工况）通过。它们是本模型的有限条件自检，不是硬件安全判据。

## 首轮问题与最小修复

初始 Ki=15 时，20 ms 斜坡结束的误差为 -0.653251 V，超过本次自检的 0.5 V 偏差条件；开环解析检验通过，问题位于跟踪速度而非开环稳态比例。对低频近似对象 `vO≈vin*duty`，线性斜坡的持续跟踪误差约为 `斜坡速度/(vin*Ki)`：100/(9×15)≈0.741 V，解释了跟随过慢的方向和量级。

保存首轮代码、完整 CSV、配置和失败日志后，在 `evidence/simulation-fix/` 隔离副本中仅将 Ki 从 15 改为 30；其他参数与测试条件均未放宽。隔离测试通过，再将这一个参数变更复制回正式模型并重新运行。斜坡末误差降为 -0.365373 V，输入变化的恢复时间也缩短；负载阶跃超调由 7.43% 增至 9.66%，说明响应速度与超调之间仍有取舍。
