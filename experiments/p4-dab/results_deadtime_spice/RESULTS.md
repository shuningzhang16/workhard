# ngspice 独立换流验证

六个局部网表均实际运行成功；包含完成、方向相反、死区不足与正反向 EPS。
每个网表使用独立 MNA 求解 L、8 个线性 C、行为端口和二极管分段电导，未调用 Python 轨迹作为激励。
每次运行前仅删除该案例的确定导出文件；随后要求新文件存在、数值有限且时间覆盖完整，避免退出码为零时误读旧数据。
与 Python 的硬钳位区别仅为二极管额外 1 mΩ 数值斜率，比较容差预设 10 mV / 0.1 mA。

最大节点差 0.00118954 V，最大电流差 6.57152e-06 A。
Python 输出采样间隔减半时最大末端节点差 1.565e-12 V。

网表、原始 ngspice 数据、日志、Python 波形及逐点误差均保留。相同教学器件假设的独立求解器一致，不等于真实 MOSFET 已验证。
