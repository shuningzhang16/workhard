# P4：LTspice 两桥等效 R-L 正反向对照

**LTspice 26.1.1 已实际运行 +30° 和 −30° 两个工况，均退出 0、没有超时。** 最后周期的 P1/P2 分别同时为正、同时为负，与独立解析模型一致。这是两个理想桥电压源之间的等效 R-L 电路验证，不是完整桥开关网络、原生 PLECS 模型或硬件验证。

## 模型与测量口径

两端电压均折算到一次侧，为 ±24 V 方波、20 kHz；L=100 µH、R=0.5 Ω，电感显式 Rser=0。网表以 IC=0 和 uic 从零电流积分 120 周期至 6 ms，仅保存最后一周期 5.95–6 ms；RAW 不包含完整启动轨迹。正相移表示第二桥滞后，负相移表示领先。

电流正方向从第一桥经 L/R 流向第二桥。P1=mean(v1·i)，P2=mean(v2·i)；正向时第一侧送出、第二侧接收，反向时接收功率为 −P1。R_loss=0.5·mean(i²)，Irms=sqrt(mean(i²))。

均值对 RAW 实际不等间隔样本做梯形时间积分，读取 RAW Offset 恢复绝对时间。LTspice 显式采用 1 ps 上升/下降沿，边沿中心对齐解析跳变；解析参考为瞬时边沿。最大步长 0.05 µs，reltol=1e−8、abstol=1e−11、vntol=1e−9；未把零边沿交给软件隐式替换。

## 原始证据与复现

[forward](forward/) 和 [reverse](reverse/) 分别保留实际命令、运行记录、CIR、LTspice LOG/ASCII RAW、解析 CSV 和单工况比较。原始运行目录为 E:/codex_ltspice_runs/dab_rl_20261106_183829_308941。

[run_dab_rl.py](run_dab_rl.py) 读取本目录的 dab_sps_forward.cir、dab_sps_reverse.cir 和 reference_rl.py。本机复现命令：

~~~powershell
& 'E:\python.exe' -B .\run_dab_rl.py
~~~

脚本使用已安装 LTspice 的 -b -ascii，在 E:/codex_ltspice_runs 下创建全新时间戳目录并保留产物；其他机器需先核对脚本中的 EXE 和 OUTPUT_ROOT。归档和本说明的整理没有再次启动仿真。

本结果不验证 PLECS 文件加载、桥门极连线、死区、磁化、器件损耗、闭环控制或保护。原生 PLECS GUI 工作及其证据单独记录。
