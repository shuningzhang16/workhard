# SPS 模型定义、推导与限制

独立低压教学模型，不是 Toshiba RD264 原厂模型；所有运行参数均为教学假设。

## 变量与方向

电路为：直流端口 V1 → 全桥 1 → 串联等效电感 L → 理想变压器 N1:N2 → 全桥 2 → 直流端口 V2。

- V1、V2 为正的直流母线电压；v1(t)、v2(t) 为两桥交流端的双极性方波，均为 50% 占空比。
- n = N1/N2；第二侧电压折算到第一侧为 v2' = n v2。
- L 是折算到第一侧的总串联电感，包含所采用等效电路中的漏感及外置串联电感；第二侧电感折算时乘 n²，不能重复计入漏感。
- iL 正方向为从全桥 1 经 L 流入变压器。报告中的峰值和 RMS 都指第一侧交流电流；按流入全桥 2 的功率交付方向，第二侧交流电流为 n iL。
- fs 为开关频率，T = 1/fs，ω = 2πfs，θ = ωt。φ > 0 表示第二侧桥滞后第一侧桥，延迟 φ/ω；代码输入为度，公式为弧度。
- p1 = v1 iL 为第一侧送入交流链路的功率，p2 = v2' iL 为链路交付第二侧的功率。平均 P > 0 为第一侧向第二侧传输，P < 0 为反向。

定义 s(θ) 在 [0,π) 为 +1、[π,2π) 为 −1，以 2π 为周期，则：

$$
v_1=V_1s(\theta),\quad v'_2=nV_2s(\theta-\phi),\quad
L\frac{di_L}{dt}=v_1-v'_2.
$$

## SPS 功率关系

记 A = V1、B = nV2。当 0 ≤ φ ≤ π，第一半周期电流斜率分别为 (A+B)/(ωL)，持续角度 φ；以及 (A−B)/(ωL)，持续角度 π−φ。选择无直流偏置的周期轨道 i(π) = −i(0)，得到：

$$
i_0=-\frac{(A-B)\pi+2B\phi}{2\omega L},\qquad
i_\phi=\frac{-(A-B)\pi+2A\phi}{2\omega L},\qquad i_\pi=-i_0.
$$

第二半周期电压和电流同时反号，功率重复。分段积分：

$$
P_2=\frac{B}{2\pi}\left[-(i_0+i_\phi)\phi+(i_\phi-i_0)(\pi-\phi)\right]
=\frac{AB}{\omega L}\phi\left(1-\frac{\phi}{\pi}\right).
$$

负相移反转功率方向，所以 −π ≤ φ ≤ π 时：

$$
\boxed{P=\frac{nV_1V_2}{2\pi f_s L}\phi\left(1-\frac{|\phi|}{\pi}\right)}.
$$

若 D = φ/π，则 P = nV1V2/(2fsL) × D(1−|D|)。D 相对于半周期归一化，不能与全周期归一化延迟 φ/(2π) 混用。本次扫描仅为 −90° 至 +90°。

## 时域积分与验证

`simulate()` 从两桥开关时刻建立分段事件表，独立求解电感方程，不使用解析功率来生成电流：

$$
i_{k+1}=i_k+\frac{v_{1,k}-v'_{2,k}}{L}\Delta t_k.
$$

先以初值零积分一周期，再减去按时间加权的电流均值，选择零偏置周期解。理想电感没有阻尼，直流偏置不会自行衰减；这不是启动或自动收敛仿真。

功率及 RMS 分别按线性电流及其平方的精确积分计算：

$$
P_2=\frac1T\sum_k v'_{2,k}\frac{i_k+i_{k+1}}2\Delta t_k,\qquad
I_\mathrm{rms}=\sqrt{\frac1T\sum_k\frac{i_k^2+i_ki_{k+1}+i_{k+1}^2}{3}\Delta t_k}.
$$

峰值取所有端点电流的最大绝对值。分段恒定电压产生分段线性电流，因此积分精确到浮点舍入水平，波形细分不影响解。程序还检查端口平均功率一致、电流均值为零、周期首尾相接，并读回落盘 CSV 重新计算功率和 RMS。

手算检查：默认 24 V／12 V、n = 2、20 kHz、100 µH，在 +30° 时电感承受 48 V 持续 T/12，电流变化 2 A，因此峰值 1 A、RMS 为 sqrt(8/9) A，功率 20 W；−30° 得到 −20 W。0° 且电压匹配时零偏置电流为零；电压比为 0.75 或 1.25 时，0° 下三角电流峰值 0.75 A、RMS 为 0.75/sqrt(3) A，但平均功率为零。

## 限制

母线为理想恒压源，变压器理想，开关瞬时切换。未包含死区、器件压降、磁化电流、磁饱和、母线电容动态、损耗、启动、方向切换瞬态及闭环保护。平均 P1 = P2 是理想模型的能量检查，不能作为真实效率或 ZVS 证据。运行命令与数据入口见 [README.md](README.md)。
